# 辰星科技 用章与合同签署流程

版本：V1.0（虚构文档，仅用于 RAG 项目演示）

生效日期：2026-02-15

## 一、印章种类

公司现有五枚印章：公章、合同专用章、财务专用章、法人章、发票专用章。均由行政部统一保管，存放于保险柜。

## 二、用章审批

| 用章类型 | 审批人 | 需附材料 |
|---|---|---|
| 公章（对外证明、函件） | 总经理 | 用章申请单、文件原件 |
| 合同专用章 | 总经理 + 法务（如有） | 用章申请单、合同定稿 |
| 财务专用章 | 财务负责人 | 付款凭证或银行单据 |
| 法人章 | 总经理本人 | 与财务专用章同时使用 |
| 发票专用章 | 财务 | 已开具发票 |

1. 严禁空白盖章：不得在空白纸张、空白合同上盖章。
2. 用章须当日登记台账，记录用途、份数、经办人、归还时间。
3. 紧急用章可先电话请示，事后 2 个工作日内补签审批单。

## 三、合同签署

1. 合同文本先经部门负责人、财务、法务（金额 1 万元以上）会签。
2. 对外签约一律使用合同专用章，不得以公章代替。
3. 合同正本两份，一份交财务归档，一份由业务部门保管；电子版同步上传至文档系统。
4. 合同变更须重新走会签，不得在手写改动处盖章确认。

## 四、外带用章

因投标、开户等需携带印章外出的，须总经理批准，由两人同行，当日归还。外带期间印章不得离身。

## 五、违规处理

未审批用章、空白盖章、伪造用章登记的，按《员工手册》严重违纪条款处理；造成损失的，公司保留追偿权利。
