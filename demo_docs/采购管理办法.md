# 辰星科技 采购管理办法

版本：V1.0（虚构文档，仅用于 RAG 项目演示）

生效日期：2026-02-01

## 一、适用范围

本办法适用于公司所有采购行为，含办公用品、软件服务、硬件设备、外包服务。员工个人垫付后报销的采购，同样适用。

## 二、金额分档与审批

| 单笔金额 | 审批人 | 需附材料 |
|---|---|---|
| 500 元以下 | 部门负责人 | 采购申请单 |
| 500 ~ 3000 元 | 部门负责人 + 财务 | 采购申请单、三家比价 |
| 3000 ~ 10000 元 | 部门负责人 + 财务 + 总经理 | 采购申请单、三家比价、合同 |
| 10000 元以上 | 总经理办公会 | 上述全部 + 预算说明 |

1. 单笔 3000 元以上必须签订书面合同，不得拆分为多笔规避审批。
2. 同一供应商同一月内累计超过 5000 元，按单笔金额上限审批。

## 三、供应商管理

1. 新供应商须提供营业执照、开户许可证，由财务归档。
2. 连续合作超过一年的供应商，每年复核一次资质。
3. 禁止向员工亲属控股的公司采购，确需合作的须书面报备总经理。

## 四、付款与发票

1. 原则上验收后 30 日内付款；预付款比例不得超过合同金额的 30%。
2. 发票抬头必须为「辰星科技有限公司」，税号匹配。
3. 无发票的采购不予付款，特殊情况须总经理书面批准。

## 五、资产登记

单价 2000 元以上的硬件设备，采购后 3 个工作日内到行政部登记固定资产，贴资产标签。
